# 산초 운정 작업 정리

뉴트라코어 산초 과제에서 운정이 맡은 11월 메모 항목들의 결과를 정리한 웹 페이지입니다.

- 보기: https://oon-jung.github.io/sancho-progress/
- 글: `content.md` (이 파일만 고치면 페이지 글이 바뀝니다)
- 모양: `index.html` (색·배치, md 를 읽어 그리는 코드)
- 그림: `assets/`

## 글 고치는 법

1. GitHub 에서 `content.md` 를 열고 연필(Edit) 버튼을 누릅니다.
2. 글을 고치고 **Commit changes** 를 누릅니다.
3. 1~2분 뒤 페이지에 반영됩니다(안 바뀌면 새로고침).

일반 마크다운(제목, 목록, **굵게**, 표, 링크)은 그대로 쓰면 됩니다. 아래는 이 페이지에서만 쓰는 표기입니다.

| 쓰는 법 | 결과 |
|---|---|
| `## 제목 {#아이디} \| 꼬리표` | 절 하나. `{#아이디}` 는 표에서 링크로 이동할 때 쓰는 이름(`[글](#아이디)`), `\| 꼬리표` 는 제목 옆 작은 글씨. 둘 다 생략 가능 |
| `[[완료]]` | 초록 표시. `[[!글]]` 은 주황 표시 |
| `> 글` | 회색 작은 설명 글 |
| `:::panel 제목` … `:::` | 테두리 상자 |
| `:::two` … `:::` | 안에 든 것 두 개를 좌우로 나란히 (상자·그림 등) |
| `@eyebrow 글` / `@footer 글` | 맨 위 작은 글 / 맨 아래 글 |

아래 블록은 ```` ``` ```` 로 감싸고, 한 줄에 하나씩 ` | ` 로 칸을 나눕니다.

| 블록 | 한 줄 형식 | 결과 |
|---|---|---|
| ```` ```facts ```` | `큰 숫자 \| 설명` | 맨 위 숫자 칸 |
| ```` ```flow ```` | `단계 이름 \| 설명` | 번호 붙은 단계 상자 |
| ```` ```bars ```` | `이름 \| 값 \| 최댓값 \| a·b·c(색)` | 가로 막대 (값÷최댓값 길이) |
| ```` ```shots ```` | `assets/그림.jpg \| 설명` | 그림 2열. ```` ```shots one ```` 은 1열 |
| ```` ```kv ```` | `항목 \| 내용` | 왼쪽 항목, 오른쪽 내용 목록 |

그림을 바꾸려면 `assets/` 에 올리고 `shots` 블록의 파일 이름을 바꾸면 됩니다.

## 내 컴퓨터에서 보기

`index.html` 을 그냥 열면 `content.md` 를 못 읽습니다. 폴더에서 아래를 실행하고 http://localhost:8000 을 엽니다.

```
python3 -m http.server 8000
```
